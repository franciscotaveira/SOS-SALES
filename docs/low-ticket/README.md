# Portfólio low-ticket — kits gerados

Gerado em 05/09/2026. São **48 rascunhos de validação**, não produtos publicados. Cada pasta contém uma oferta, um guia PDF, um template Notion e, quando aplicável, um CSV inicial.

## Regras de uso

- Não publicar ou cadastrar na Cakto sem conferir o catálogo ativo e os complementos do EKO.
- Cada kit resolve uma tarefa finita; operação recorrente, automação e multiusuário pertencem a uma solução maior.
- Todos os exemplos são fictícios. Substitua-os somente após revisar privacidade e autorização.
- Preço, promessa e volume de procura continuam sujeitos a validação.
