## Cartão da oferta

- **Comprador:** dono, autônomo ou gestor de pequena equipe. Ferramentas com premissas editáveis, exemplo e instruções; sem depender de programação ou implantação individual..
- **Formato:** Planilha/Notion + PDF.
- **Preço:** hipótese a testar; definir somente após validar compra e esforço de suporte.
- **Resultado comprado:** Simulador do efeito de diferentes descontos sobre contribuição, usando custos informados.
- **Origem no catálogo:** grupo 6, ID 33.
- **Sobreposição:** Hipótese acrescentada ao catálogo; criar e validar do zero.

## Promessa de uma frase

> Resolva “simulador do efeito de diferentes descontos sobre contribuição, usando custos informados” com um modelo finito que você copia, preenche e usa em um caso real.

## O que está incluído

1. [Guia em PDF](./GUIA.pdf) e [fonte editável](./GUIA_PDF.md);
2. [Template pronto para duplicar no Notion](./NOTION_TEMPLATE.md);
3. exemplo fictício, checklist de conclusão e limites de uso;
4. arquivo de dados quando o produto se beneficia de planilha.

## O que não está incluído

- implantação, automação, gestão de campanha ou acesso a contas;
- consultoria ilimitada ou personalização individual;
- promessa de vendas, leads, agenda cheia ou conformidade;
- dados reais de clientes, depoimentos ou credenciais.

## Como a pessoa usa

1. Duplique a página ou abra o PDF.
2. Preencha um único caso real.
3. Execute a rotina uma vez.
4. Registre evidência, pendência e próxima ação.
5. Repita apenas depois de revisar o resultado.

## Critério de sucesso do piloto

- o comprador completa o artefato sem acompanhamento individual;
- consegue explicar a diferença entre o template e o EKO;
- usa o resultado em até sete dias;
- aponta uma melhoria concreta ou decide que a dor não é prioritária.
