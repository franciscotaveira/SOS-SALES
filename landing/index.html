Segurança Multi-Tenant & RLS

A inteligência artificial qualifica a conversa, sugere respostas comerciais pertinentes e organiza os dados, mas sua equipe mantém a aprovação e o controle final sobre orçamentos, compromissos e envios.
Quando um cliente clica no seu anúncio do tipo Click-to-WhatsApp (CTWA), a Meta envia os identificadores do clique, campanha e criativo. O Chat Sales associa esses parâmetros ao contato no momento da entrada. Quando a venda é concluída via Pix no WhatsApp, nossa integração oficial com a Meta Conversions API (CAPI) devolve o evento de Purchase com o valor real para retroalimentar seu Pixel de forma 100% auditável.
O Chat Sales possui arquitetura Dual-Engine: você pode conectar tanto o WhatsApp Oficial (Meta Cloud API / WABA) com selo de verificação e templates aprovados, quanto canais ágeis. Se você já anuncia na Meta, o uso da Cloud API oficial é o mais recomendado para evitar qualquer risco de bloqueio de número.
